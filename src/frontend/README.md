# RealTest frontend

Next.js 16 (App Router) frontend for RealTest. See the [repository root README](../../README.md)
for full setup instructions, environment configuration, and architecture notes.

Quick reference:

```bash
npm install
npm run dev      # start the dev server on http://localhost:3000
npm run lint      # ESLint
npx tsc --noEmit  # TypeScript type check
npm run build     # production build
```
